# Delivery-Flowers

> A marketplace concept for discovering flower shops, browsing products, and organizing flower delivery.

**Stack:** PHP · MySQL · JavaScript · HTML5 · CSS3

## 🌸 Overview

Delivery-Flowers is a web project concept for a flower-delivery marketplace. The platform is designed around multiple flower shops, product catalogs, customer accounts, and order management.

## ✨ Planned / Implemented Concept

- 🏪 Multiple flower shops
- 🌷 Product catalog for each shop
- 👤 Customer registration and login
- 🛒 Product and order workflow
- 📦 Order management
- 📧 Email notifications
- 🛠️ Administrative shop management
- 📱 Responsive interface
- 🗄️ MySQL database

## 🧱 Architecture

The project uses a traditional PHP/MySQL architecture without a frontend framework, with JavaScript used for interactive interface features.

## 📌 Status

Personal development project focused on building a practical marketplace architecture and improving PHP/MySQL application development.
