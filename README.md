# Delivery-Flowers

> A marketplace concept for discovering flower shops, browsing products, and organizing flower delivery.

**Stack:** PHP · MySQL · JavaScript · HTML5 · CSS3

## 🌸 Overview

Delivery-Flowers is a web project concept for a flower-delivery marketplace. The platform is designed around multiple flower shops, product catalogs, customer accounts, and order management.

## ✨ Planned / Implemented Concept

- 🏪 Multiple flower shops
- 🌷 Product catalog for each shop
- 👤 Customer registration and login
- 🛒 Product and order workflow
- 📦 Order management
- 📧 Email notifications
- 🛠️ Administrative shop management
- 📱 Responsive interface
- 🗄️ MySQL database

## 🧩 Architecture

The project follows a traditional PHP/MySQL architecture without a frontend framework. JavaScript is used for interactive interface features, while PDO is used for database access.

```text
Delivery-Flowers/
├── dashboard/
├── includes/
├── admin/
├── assets/
├── index.php
└── shop pages / product pages
```

## 🎯 Project Goals

- Build a marketplace structure around independent flower shops
- Practice relational database design
- Implement customer and order workflows
- Explore shop administration and product management
- Improve responsive UI development with PHP and JavaScript

## 📌 Status

Personal development project focused on building a practical marketplace architecture and improving PHP/MySQL application development.
